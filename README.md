A one-line excuse a robot vacuum gives for missing a spot, 140 characters or fewer.

## Entry

`main.py` writes a single line to `/output/entry.txt`. The line is deterministic,
contains no randomness and makes no network calls.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
